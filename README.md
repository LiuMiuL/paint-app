# 그림판

모바일과 PC에서 바로 쓰는 한국어 그림판 PWA입니다. 빌드 도구나 외부 CDN 없이 순수 HTML/CSS/JS로만 동작하며, 설치하면 오프라인에서도 열립니다.

- 배포 주소: <https://liumiul.github.io/paint-app/> (저장소 Settings → Pages에서 Source를 `main` / `/ (root)`로 설정하면 열립니다)
- 저장소: <https://github.com/LiuMiuL/paint-app>

## 기능

| 구분 | 내용 |
| --- | --- |
| 그리기 | 펜(곡선 보간), 붓(부드러운 가장자리), 연필(가는 선), 형광펜(반투명), 지우개, 직선, 사각형, 원 |
| 도형 채움 | 사각형·원 도구에서 `채움`을 켜면 안쪽까지 칠한 도형 |
| 채우기 | 페인트통(Flood Fill) — 누른 지점과 같은 색 영역을 한 번에 채움 |
| 글자 | 캔버스를 누른 자리에 글자 입력, Enter로 확정 (크기는 굵기 슬라이더) |
| 스포이트 | 그림에서 색을 집어 오고, 손을 떼면 쓰던 도구로 돌아감 |
| 사진 | 갤러리·카메라 사진을 불러와 그 위에 그리기 (실행 취소 가능) |
| 색 | 프리셋 10색 + 색 고르기 창(HEX 입력, RGB·HSV 슬라이더, 기기 색 선택기) |
| 편집 | 자르기(영역을 끌어 고르면 캔버스에 맞게 키움), 90° 회전, 좌우·상하 대칭, 크기 조정(픽셀·비율, 비율 유지) — 모든 레이어에 적용, 실행 취소 가능 |
| 레이어 | 새 레이어, 고르기, 보이기/숨기기, 투명도, 순서 바꾸기, 삭제(확인 후) |
| 배경색 | 편집 창에서 종이 색 변경 (PNG에도 반영, 실행 취소 가능) |
| 확대/축소 | 두 손가락 벌리기·오므리기와 이동, Ctrl+휠, `+`/`-`/`0`, 편집 창 버튼 (최대 800%) |
| 화면 | 다크 모드 — 자동(기기 설정)/밝게/어둡게. 이 설정만 브라우저에 기억 |
| 굵기 | 1~80 슬라이더, 도구별 배율(형광펜 ×2.4, 지우개 ×2.6) |
| 되돌리기 | 실행 취소 / 다시 실행 최소 80단계, 전체 지우기. 오래된 단계는 바탕 그림으로 굳혀 지워지지 않음 |
| 제스처 | 두 손가락 탭 = 실행 취소, 세 손가락 탭 = 다시 실행, 두 손가락 움직이기 = 확대/축소·이동 |
| 저장·공유 | 배경색을 채운 PNG 다운로드 (`그림판_YYYYMMDD_HHMMSS.png`), 휴대폰에서는 공유 버튼으로 카톡·메시지 등에 바로 보내기 |
| 입력 | 마우스, 손가락, S펜(필압 지원), 멀티터치 간섭 차단 |
| PWA | 홈 화면 설치, 오프라인 실행, 자동 업데이트 |

## 사용법

1. 아래쪽 도구바에서 도구를 고릅니다.
2. 색상바에서 색과 굵기를 정합니다.
3. 캔버스를 그립니다. 도형 도구는 끌어서 크기를 정하고, `Shift`를 누르면 정사각형·정원이 됩니다.
4. 잘못 그렸으면 **두 손가락으로 화면을 톡** 치면 실행 취소, **세 손가락**이면 다시 실행입니다.
5. 오른쪽 위 편집 버튼(슬라이더 모양)에서 회전·대칭·크기 조정·배경색·레이어·다크 모드를 바꿉니다.
6. 오른쪽 위 사진 버튼으로 사진을 불러와 그 위에 그릴 수 있습니다.
7. 저장 버튼으로 PNG를 내려받거나, 휴대폰에서는 공유 버튼으로 바로 보냅니다.
8. 저장하지 않고 창을 닫으려 하면 브라우저가 한 번 확인합니다.

### 키보드 단축키

| 키 | 동작 |
| --- | --- |
| `B` / `U` / `P` | 펜 / 붓 / 연필 |
| `H` / `E` | 형광펜 / 지우개 |
| `L` / `R` / `O` / `G` | 직선 / 사각형 / 원 / 채우기 |
| `T` / `I` / `C` | 글자 / 스포이트 / 자르기 |
| `+` / `-` / `0` | 확대 / 축소 / 100% |
| `F` | 사각형·원 안쪽 채우기 켜기/끄기 |
| `Ctrl(⌘)+O` | 사진 불러오기 |
| `Ctrl(⌘)+Z` | 실행 취소 |
| `Ctrl(⌘)+Shift+Z`, `Ctrl+Y` | 다시 실행 |
| `Ctrl(⌘)+S` | PNG 저장 |
| `Ctrl+Delete` | 전체 지우기 |
| `[` / `]` | 굵기 1씩 줄이기 / 늘리기 |

## 설치(PWA)

- **Android(Chrome)**: 주소를 연 뒤 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
- **iPhone(Safari)**: 공유 → "홈 화면에 추가"
- **PC(Chrome/Edge)**: 주소창 오른쪽의 설치 아이콘

설치 후에는 네트워크 없이도 실행됩니다.

## 파일 구조

```
index.html              화면 구조 (툴바, 캔버스, 색상바)
styles.css              레이아웃·테마 (반응형, 세이프 에어리어 대응)
app.js                  그림판 로직 전체 (캔버스, 도구, 히스토리, 저장)
sw.js                   서비스 워커 (오프라인 캐시)
manifest.webmanifest    PWA 매니페스트
icon-192.png            아이콘
icon-512.png            아이콘
icon-512-maskable.png   마스크용 아이콘
tools/make_icons.py     아이콘 생성 스크립트 (Pillow)
```

## 동작 원리

- **고해상도 캔버스**: 캔버스 비트맵을 `devicePixelRatio`(최대 3배)로 키우고 `ctx.setTransform`으로 보정합니다. 그리기 좌표는 모두 CSS 픽셀 기준입니다.
- **붓 곡선**: 입력점 사이의 중점을 잇는 2차 베지어로 이어 부드럽게 그립니다. 실시간으로 그리는 모양과 저장된 점을 다시 그리는 모양이 같도록 같은 함수를 씁니다.
- **히스토리**: 그림을 비트맵으로 저장하지 않고 연산(점 배열·도형·채우기·글자·사진·지우기)만 쌓은 뒤, 되돌릴 때 처음부터 재생합니다. 100단계를 넘으면 앞쪽 20단계를 바탕 그림 한 장으로 굳혀, 오래 그려도 처음 그린 그림이 사라지지 않습니다.
- **두 손가락 탭**: 첫 손가락이 닿은 뒤 0.35초 안에 두 번째 손가락이 닿으면 제스처로 보고, 첫 손가락이 그리기 시작한 획을 흔적 없이 취소합니다. 손가락이 움직이지 않고 0.7초 안에 떨어지면 실행 취소합니다.
- **사진**: 불러온 사진은 화면 해상도로 줄인 사본만 메모리에 보관합니다(기기에 따로 저장하지 않음).
- **페인트통**: 캔버스 픽셀을 읽어 스캔라인 Flood Fill로 같은 색 영역을 채웁니다(허용 오차 40). 채운 결과는 연산으로 기록되어 되돌리기·다시 실행에서 동일하게 재현됩니다.
- **PNG 저장**: 투명 픽셀 위에 흰 배경을 깔아 합성한 뒤 저장하므로, 내려받은 파일이 검게 나오지 않습니다.

## 개발

```bash
# 로컬 확인 (서비스 워커는 http(s)에서만 동작)
python3 -m http.server 8000
# http://localhost:8000
```

- 파일을 고친 뒤에는 브라우저를 새로 고치면 반영됩니다. 서비스 워커가 네트워크 우선이라 온라인 상태에서는 항상 최신 파일을 받습니다.
- 아이콘을 다시 만들려면 `python3 tools/make_icons.py` (Pillow 필요).

## 배포

`main` 브랜치에 푸시하면 GitHub Pages(<https://liumiul.github.io/paint-app/>)에 자동 반영됩니다. Pages가 아직 꺼져 있다면 저장소 Settings → Pages에서 Source를 `main` / `/ (root)`로 한 번만 지정하면 됩니다.

## 알려진 제한

- 화면 크기가 바뀌면(회전·창 크기 변경) 그린 내용은 유지되지만, 캔버스 밖으로 밀려난 부분은 잘립니다.
- 채우기는 색이 비슷한 경계(허용 오차 40)에서 멈추므로, 아주 옅은 그라데이션 위에서는 번질 수 있습니다.
- 캔버스 크기는 화면에 맞춰 정해집니다. 크기 조정·회전·자르기는 그 안에서 그림을 늘이거나 줄이는 방식이라, 회전하면 그림 전체가 보이도록 작아지고 크게 키우면 밖으로 나간 부분은 잘립니다.
- 레이어 순서·투명도·보이기는 실행 취소 대상이 아닙니다. 레이어를 삭제하면 그 레이어의 실행 취소 기록도 사라집니다.
- 그림은 브라우저 메모리에만 있습니다. 새로 고치면 사라지므로 필요하면 PNG로 저장하세요.
